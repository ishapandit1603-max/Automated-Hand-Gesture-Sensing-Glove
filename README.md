# 🧤 **Gesture-Controlled Smart Glove**

> **A wearable gesture-based interface that enables users to control digital applications through intuitive hand movements, with potential applications in design software such as AutoCAD.**

## 🖐️ **Project Overview**

The **Gesture-Controlled Smart Glove** translates hand gestures into control commands, enabling users to perform actions such as **zoom in and zoom out** without directly interacting with traditional input devices. The system can support **hands-free interaction with design and engineering software**.

## ✨ **Key Features**

- 🖐️ **Hand Gesture Recognition**
- 🔍 **Zoom In / Zoom Out Control**
- 💻 **Application-Level Interaction**
- 🧤 **Wearable & Hands-Free Interface**
- 📐 **Potential AutoCAD Integration**
- ⚡ **Real-Time Gesture-Based Control**

## 🛠️ **Tech Stack**

**Microcontroller:** NodeMCU  
**Programming & Development:** Arduino IDE  
**Interface:** Gesture-Controlled Glove

## ⚙️ **Workflow**

**Hand Gesture** 🖐️ → **Gesture Detection** 🔍 → **NodeMCU Processing** ⚙️ → **Control Command** 💻 → **Application Action** 📐

## 🎯 **Objective**

To develop a **wearable human–computer interaction system** that enables intuitive, hands-free control of digital applications through **natural hand gestures**, particularly for design and engineering workflows.
